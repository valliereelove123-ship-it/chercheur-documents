Recherche documentaire

Trouve des documents, partout où ils vivent.

Entre un sujet. Choisis tes formats. L'outil ouvre des recherches sur tout le web — sans restriction de site — plus les moteurs spécialisés qui agrègent déjà des millions de documents institutionnels (ONG, gouvernements, universités, organisations).

☀️
Chaque carte ouvre une recherche Google filtrée par domaine et type de fichier — les documents restent sur leurs sites d'origine (légaux, publics). Les domaines par secteur sont volontairement larges ; affine le sujet pour resserrer les résultats.
